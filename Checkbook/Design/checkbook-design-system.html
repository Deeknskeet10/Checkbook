Checkbook Design System

How every HTML Web Resource and PCF component in ARNG Checkbook should look and behave.

Baseline: Itemized Details Grid (pcf/ItemizedDetailsGrid) · Fluent UI v9 · checkbookTheme (webLightTheme + brand #2086ff) · v1.5 · November 2026

01Design principles

Quiet chrome, loud dataBorderless buttons, soft fills and muted context text. The numbers and the user's edits are what stand out.
Color carries meaning, never decorationGreen adds, red deletes, blue is brand/interactive, grey is neutral. A color used for one meaning is never reused for another.
Show affordance on hoverEditable fields sit at a grey fill and "wake up" (white + blue border) on hover. Buttons gain a background only on hover.
State without layout shiftSticky header and totals stay put, disabled controls keep their shape, and action badges sit inline after the item name in a cell that already wraps. Nothing jitters.
Disabled = desaturatedDisabled controls keep their color identity but drop to 0 saturation at 70% opacity, so users still recognize the control.
Tokens over hexPCF uses Fluent v9 tokens.*. HTML uses the --cb-* variables. A raw hex in a component is a review flag unless it is in the token table.

03Typography

One family: Segoe UI (Fluent tokens.fontFamilyBase). Weight 600 is the emphasis weight. 700 is used in only three places: table headers (11px / 700 / UPPERCASE), action badges (10.5px / 700 / UPPERCASE) and the $ / # prefix of numeric boxes. Never use 700+ anywhere else in a component.

Money & quantity

The two numeric subtypes share one look: a grey #f7f7f7 box with no border at rest and a 6px radius (white with a border on hover and focus, like every editable input), a bold symbol on the left, and the value right-aligned in tabular figures. Money ($) is any column the form calls Money, Currency or an amount (Requested, Validated, Funded, …). Quantity (#) is any count of items. In Dataverse both are usually Double columns that store a plain number. The symbol is part of the box, never part of the value.

13Icon library (raw SVG)

All icons use a 640 × 640 viewBox and render at 20px (18px for Refresh, 16px inside search fields). The fill/stroke color is baked into the icon from the token table, so filter: saturate(0) handles the disabled state. Exception: status and badge icons use currentColor, so they always match their tag's text.

  • Font Awesome Free 7 (solid) is the source of record. To add an icon, copy it from fontawesome.com (Free, Solid, v7) and keep its license comment. Font Awesome Free icons are CC BY 4.0.
  • Checkbook line icons are simple stroke glyphs drawn for this system where FA has nothing in the repo yet. They use stroke width 48–64 with round caps to match FA's weight.
  • In PCF, wrap each icon as a React.FC with aria-hidden="true" and put it in the control's designSystem.tsx (see the .md file, §10). In HTML, paste the SVG inline.
